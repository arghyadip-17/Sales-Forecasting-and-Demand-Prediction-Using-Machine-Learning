# 📊 Sales Forecasting and Demand Prediction Using Machine Learning 

## 📌 Project Overview
This project focuses on forecasting future sales and predicting demand using historical retail sales data.  
A time series–based machine learning approach is applied to identify trends and seasonal patterns, helping businesses make informed decisions related to inventory planning, supply chain management, and sales strategy.

The project integrates:
- Machine Learning (Time Series Forecasting)
- Python-based data analysis
- Power BI dashboard visualization

---

## 🎯 Objectives
- Analyze historical sales data
- Forecast future sales using machine learning models
- Evaluate forecast accuracy using standard metrics
- Visualize results using Power BI
- Provide actionable recommendations for management

---

## 🧠 Machine Learning Model
  - Captures both trend and seasonality
  - Suitable for retail sales time series
  - Simple, interpretable, and effective

### Workflow:
1. Data cleaning and preprocessing
2. Monthly aggregation of sales data
3. Train-test split (last 6 months as test set)
4. Model training and forecasting
5. Performance evaluation

---

## 📈 Forecast Accuracy Metrics
The forecasting model was evaluated using the following metrics:

| Metric | Value |
|------|------|
| MAE  | ≈ 5,770 |
| RMSE | ≈ 7,272 |
| MAPE | ≈ 14.48% |

📌 A MAPE below 20% indicates good forecasting accuracy for retail sales data.

---

## 📊 Power BI Dashboard
The Power BI dashboard includes:
- Actual vs Forecasted Sales comparison
- Monthly sales trend analysis
- Regional and category-wise sales distribution
- Future sales forecast visualization

These dashboards help stakeholders easily interpret forecast results and support business decisions.

---

## 💡 Recommendations for Management
- Increase inventory before forecasted peak demand periods
- Align procurement planning with predicted sales
- Plan promotions during high-demand months
- Update the forecasting model periodically with new data
- Extend forecasting to category or product level in future
